# Gravity Flip

Petit jeu 2D de gravité inversée, inspiré de Gravity Guy, fait en HTML, CSS et JavaScript pur avec l'élément canvas.

## Principe
Le joueur avance automatiquement. Un clic ou la barre d'espace inverse la gravité : il passe du sol au plafond. Il faut éviter les pics qui défilent.

## Lancer le jeu
Ouvre `index.html` dans ton navigateur. Aucune installation n'est nécessaire.

## Structure du projet
- `index.html` : la page et le canvas
- `css/` : les styles
- `js/` : le code du jeu (joueur, obstacles, collisions, interface, boucle principale)
